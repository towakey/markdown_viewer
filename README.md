# markdown_viewer

外部ライブラリ不使用の単独Markdownビューワー/エディタ。IIS + Python 3.7 CGI (標準モジュールのみ) で動作します。

## ファイル

- `index.html` — ビューワー。`MD_FILE` で指定したファイルを表示。ローカルファイルも開ける。
- `editor.html` — エディタ。左に編集、右にライブプレビュー。サーバー上のファイルを読み込み・保存できる。
- `md.js` — Markdownパーサと設定 (`MD_FILE`)。機能追加はここに書けば両ページに反映される。
- `md.css` — 共通スタイル。
- `save_md.py` — 保存用CGI。editor.html と同じフォルダに置く。

## セットアップ (IIS)

1. すべてのファイルを同じフォルダに置く。
2. `.md` を表示したい場合は IIS の MIME マップに追加するか、ファイルを `.txt` にリネーム (既定の `MD_FILE` は `index.txt`)。
3. 保存を使うには Python CGI のハンドラ設定 (他のCGIと同じ) と、フォルダへの書き込み権限が必要。
4. `save_md.py` は同じフォルダ内の `.md`/`.markdown`/`.txt` のみ上書き可能 (パス指定は拒否)。

## 記法

- テーブル: `| A | B |` と `A | B` (外側パイプ省略) の両方に対応。`:---` `:---:` `---:` で寄せ指定。
- セル背景色: `{色}テキスト{/色}` (例: `{red}NG{/red}` `{#ff9}注意{/#ff9}` `{ffcccc}`)。セル全体を囲めばセル背景、文中ならインライン背景。
- フォルダリンク: `\\サーバー\共有\dir` や `Y:\dir` は直書きでリンク化。`[表示名](パス)` でも可。クリックでパスをコピーしつつ file:// で開き、横の「コピー」ボタンでもコピーできる。
- リンクURLは `()`・`※`・全角空白を含められる (例: `[x](\\srv\a(b)c)`)。閉じていない `)` も、直後が空白・句読点でなければURLの一部とみなす。`[表示](<パス>)` のように `<...>` で囲むのが確実。
